# Vrienden Run
Een renspel in de stijl van Kaasje / de Chrome dino-game. Spring en buk om obstakels te ontwijken, verzamel kaas en maak je vrienden na als poppetjes.

Open `index.html` in een browser (of serveer de map, bijv. `python3 -m http.server`).

Besturing: ↑ / spatie = springen, ↓ = bukken. Op touchscreen: rechter helft = springen, linker helft = bukken.
