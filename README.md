# Vrienden Run
Een renspel door een bruin café, in de stijl van Kaasje / de Chrome dino-game. Spring en buk om obstakels te ontwijken en maak je vrienden na als poppetjes (man of vrouw).

- **Spel 1:** groene flesjes verzamelen, sneller tempo.
- **Spel 2:** wijnglazen verzamelen, rustiger tempo.
- Raak je iets, dan valt je poppetje flauw en kies je: opnieuw spelen of hoofdmenu.

Open `index.html` in een browser (of serveer de map, bijv. `python3 -m http.server`).

Besturing: ↑ / spatie = springen, ↓ = bukken, Esc = hoofdmenu. Touchscreen: rechter helft = springen, linker helft = bukken.
