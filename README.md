# Vrienden Run
Een renspel door een bruin café, in de stijl van Kaasje / de Chrome dino-game. Spring en buk om obstakels te ontwijken en maak je vrienden na als poppetjes.

- **Spel 1 (bier):** pak groene bierflesjes, je bierglas links in beeld wordt leger.
- **Spel 2 (wijn):** pak wijnglazen, je wijnglas gaat sneller leeg (sterkere drank). Zelfde tempo als spel 1.
- **Shotjes** die voorbij komen vullen je glas weer een beetje bij.
- **Glas leeg = gewonnen.** Raak je een obstakel, dan val je flauw en moet je opdrinken wat er nog in je glas zit.
- **Afstandsmeter** linksboven met een mini-portret van je poppetje. Bij elke 100 meter krijgt het een feestmutsje (tik erop voor een verrassing).
- **Poppetjes-maker:** man/vrouw, lengte, postuur, houding, bochel, borst, buik, billen, huid, ogen, kapsel, haarkleur, baard, bril, kleding, schoenen en hoofddeksel.

Open `index.html` in een browser (of serveer de map, bijv. `python3 -m http.server`).

Besturing: ↑ / spatie = springen, ↓ = bukken, Esc = hoofdmenu. Touchscreen: rechter helft = springen, linker helft = bukken.
